# 外刊阅读器

A local PDF reader for English magazines: click a word for Chinese and English
definitions, drag a sentence for translation, save words to a spaced-repetition
wordbook. Dictionary lookup works fully offline.

读英文外刊 PDF 用的本地工具。点一下单词出中文释义和英文词典释义，拖选一句出整句翻译，能听英音美音，收录的生词按艾宾浩斯曲线排复习。查词全程离线，不联网也能用。

没有账号，没有后端，不上传任何数据。所有东西都在你本机。

## 先把话说清楚

这个工具不附带任何文章内容，也不提供任何下载渠道。你需要自己准备有权限阅读的 PDF。

仓库里不含任何刊物正文，`sample/` 和 `library/` 都在 `.gitignore` 里。请不要把有版权的杂志提交到本仓库，PR 会被拒绝。

## 快速开始

需要 Python 3.9 以上，只用标准库，不用装依赖。

```bash
git clone https://github.com/georgewang-dot/pdf-dict-reader.git
cd pdf-dict-reader
python3 serve.py
```

会自动打开浏览器到 `http://localhost:8731`，点「打开 PDF」选一本外刊就能用。端口被占用会自动往后找。

编辑器里调试也可以用任意静态服务器，只是生词本落盘、书架存储、翻译代理这几个接口会失效，功能会降级。

### 装成 macOS 应用

```bash
python3 build_app.py
```

会画图标、打包成 `外刊阅读器.app` 并复制到 `/Applications`，之后双击就能开，不用碰终端。启动器会在后台起本地服务，关掉窗口服务还在，下次秒开。

### 单文件版

```bash
python3 build_standalone.py
```

生成一个 31MB 的 HTML，pdf.js 和 77 万词条全部内嵌，拷到任何机器上双击就能查词，不需要 Python。

`file://` 协议下浏览器不让存文件本体，所以单文件版的书架只能记页码，不能缓存 PDF。想要完整书架用 `.app` 或者服务器模式。

## 功能

**查词**。单击任意单词出卡片，中文释义在上，英文词典释义在下，带音标、柯林斯星级、牛津核心标记、词频。点不到会兜三层，先直接查，再查词形还原表处理复数时态，最后按常见词尾规则猜一次，猜出来的会标「按 xxx 推断」。

**行尾连字符**。长单词在行尾被 `-` 拆成两半时，点任一半都会拼成整词查询。拼起来查不到会再试保留连字符的写法。

**句子翻译**。拖选两个词以上就走翻译，卡片里原文和译文对照，可一键复制、重新翻译。翻译引擎在「设置」里选：

- 免费在线翻译，免配置，需要联网，机器翻译水平
- 自定义 OpenAI 兼容接口，填地址、Key 和模型名，译文明显更地道。填完可以点「测试接口」验证

都不通时退化成本地词库逐词对照，并说明没连上网。

**发音**。卡片上的「英音」「美音」，优先播在线词典原声，网络不通时退回系统语音合成，按 en-GB / en-US 选声音。

**书架**。打开过的 PDF 自动进书架，每本记住读到第几页和缩放比例，下次打开自动跳回去。可以同时放多本，条目显示页数、大小、进度和最后阅读时间。书的身份按文件内容算，改名不影响进度。

**生词本**。卡片上按「收录」，自动带出处文件名、页码和原句。顶栏红色角标显示今天到期几个。**收录过的词在正文里自动加红色下划线**，删掉后下划线一起消失。

**复习**。艾宾浩斯排期，间隔 1、2、4、7、15、30、60 天。「记得」前进一档，「忘了」打回第一档，走完标记已掌握。

**导出**。Anki 文本、带 BOM 的 CSV、完整 JSON 备份。Anki、不背单词、墨墨都能直接导入，字段顺序是 单词 / 音标 / 中文 / 英文 / 出处。

**每日提醒**。填个时间，装一个 launchd 任务，每天弹系统通知。装不上会自动退回导出 `.ics`，双击导入日历。这一项只支持 macOS。

**缩放**。顶栏加减号、「适应宽度」，或者触控板两指捏合，以指针位置为锚点，不会把浏览器页面一起放大。

## 操作

| 想干什么 | 怎么操作 |
|---|---|
| 查一个词 | 单击它 |
| 翻一整句 | 按住拖选这句 |
| 关闭卡片 | 点页面空白处、按 Esc、或者滚动页面 |
| 放大缩小 | 触控板两指捏合，或顶栏的 +/− |
| 收进生词本 | 卡片上按「收录」 |
| 换一本书 | 顶栏「书架」，点那一本的「继续」 |
| 从书架移除 | 条目右侧「移除」，进度一起删掉 |
| 回到上次那一页 | 什么都不用做，打开就跳回去 |

## 目录结构

```
index.html  style.css   界面
app.js                  主程序，渲染、取词、弹窗、缩放、下划线
dict.js                 词库查询，按字母分片按需加载
translate.js            句子翻译，引擎链式回退
speak.js                发音
wordbook.js             生词本、艾宾浩斯排期、导出
shelf.js                书架，服务器走接口，单文件版退到 localStorage
serve.py                本地服务器，静态文件 + 翻译代理 + 生词本 + 书架 + 提醒安装
reminder.py             launchd 调用的提醒脚本
build_dict.py           从 ECDICT 原始数据生成词库分片
build_standalone.py     内嵌全部资源生成单文件 HTML
build_app.py            生成图标、应用包并安装
data/dict/              54 个词库分片，按首字母切，共 60MB
vendor/pdfjs/           pdf.js 4.10.38
```

生成的运行期文件，不入库：`wordbook.json`、`shelf.json`、`library/`。

## 词典数据

词库来自 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 协议，77 万词条，含中文释义、英文释义、音标、柯林斯星级、词频和词形还原表。

`data/dict/` 里的 54 个 TSV 是从 ECDICT 快照切出来的派生数据，按首字母分片，前端按需 fetch，不加载整库。想自己重建：

```bash
python3 build_dict.py
```

会去拉 ECDICT 的 `ecdict.csv` 和 `lemma.en.txt`，大约 68MB，切分后覆盖 `data/dict/`。

## 已知边界

- **扫描件查不了**。必须有文本层。判断方法：在预览里能不能用鼠标选中文字。
- **新词和缩写会查不到**。词库是静态快照，hyperscale、公司名、人名这类没收录属于正常。
- **免费在线翻译水平有限**。长难句会生硬，想要地道就在设置里填大模型接口。
- **在线发音接口可能不通**。这时退回系统语音，是机器合成，不是真人。
- **单文件版不加载 CJK 字体映射**。中文 PDF 可能显示异常，英文外刊不受影响。
- **下划线位置是渲染时算的**。窗口大幅改尺寸后如果错位，滚一下重绘即可。
- **内容完全相同的两份 PDF 会被当成同一本**。身份按字节算，改名不影响，反过来字节一致只留一条记录。
- **书架占磁盘**。每本在 `library/` 留一份完整副本，80 页的外刊约 13MB，移除才会真删。
- **每日提醒只支持 macOS**。用的是 launchd。
- **`.app` 只支持 macOS**。其他平台用 `python3 serve.py` 或者单文件版。

## 路线图

第一版是能用的自用工具，接下来想补这些，欢迎提 issue 讨论优先级。

先做，纯前端，不动数据链路：

- 全文搜索，命中列表点击跳转并高亮
- 按 PDF 书签生成目录侧栏
- 记住页内滚动位置，现在只记到第几页
- 键盘快捷键，翻页、缩放、收录、搜索
- 生词本按书、按掌握状态、按加入时间筛选
- 从生词本跳回原文那一页看原句

再做，要动翻译和学习链路：

- 语境选义，把所在句子传给大模型，从现有义项里挑当前语境那一条
- 复习增加中译英方向，现在只有英译中
- 按忘记次数动态收缩间隔，替代固定档位
- 夜间模式

暂不做：

- 手机和 iPad 端，是另一套工程
- 用大模型替代词库，慢、花钱、断网就废

## 反馈

用着有问题就提 issue，麻烦带上这几样：

- 系统版本和 Python 版本
- 是 `.app`、`python3 serve.py` 还是单文件版
- 控制台报错，浏览器按 F12 看
- 出问题的词或者页码，方便复现

功能建议直接说场景，不用想实现方式。
